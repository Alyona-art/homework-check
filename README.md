# Проверка работ

Учитель создаёт работу (число заданий и вариантов), заполняет эталон. Ученик выбирает фамилию и вариант, вводит ответы. Сводная таблица: зелёный — совпало, красный — нет, жёлтый — не сдавал.

## Запуск локально

Нужен **Node.js 22.5+** (встроенный `node:sqlite`).

```bash
cp .env.example .env   # отредактируйте
npm install
set -a && source .env && set +a
npm start              # http://localhost:3001
```

- **Учитель:** ФИО + `TEACHER_CODE` → дети, работы, ключ, таблица сравнения.
- **Ученик:** `STUDENT_CODE` → фамилия → работа → вариант → ответы.
