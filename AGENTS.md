# Правила работы с проектом

- Ассистент не запускает команды самостоятельно. Это включает команды в терминале, сборку, запуск приложения или сервера, миграции, скрипты и любые другие исполняемые действия.
- Ассистент не проводит проверки самостоятельно: не запускает тесты, линтеры, проверку синтаксиса, запросы к API и не проверяет приложение в браузере.
- Если для задачи нужны запуск или проверка, ассистент пишет в чат точные команды, которые пользователь может выполнить сам, и объясняет, что проверить и какой результат ожидать.
- Ассистент не утверждает, что изменение проверено, если пользователь не сообщил результат проверки.
